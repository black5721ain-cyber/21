核心 AI 辨識能力

🦔
嗨！我是你的專屬刺蝟助手豆豆！我會幫你把鏡頭底下的斑馬線抓出來，還能用像素分析幫道路打分數喔！

本系統基於 ONNX Runtime Web 與 YOLO26n 模型，提供以下強大功能：

  • 斑馬線偵測：精準標定畫面中的斑馬線（綠框 #00FF00，附帶信心百分比）。
  • 標線狀態分析：透過灰階直方圖計算對比與能見度。
  • 駕駛視角空間評估：評估視線盲區與空間壓迫佔比。
  • 風險分級報告：綜合評分並產出具體改善建議。

評估標準（五項指標）

所有門檻皆採教學示範預設值：

  • 1. 標線清晰度 (0~2分)：對比度 ≥80 (0分) | 50~80 (1分) | <50 (2分)
  • 2. 框內能見度 (0~2分)：平均灰階 70~200 (0分) | 40~70或200~230 (1分) | 其他 (2分)
  • 3. 完整度 (0~1分)：任一側距邊緣 < 2% 即計 1 分
  • 4. 視線盲區 (0~1分)：底邊距離比例 < 0.18 計 1 分
  • 5. 空間壓迫 (0~1分)：高度佔比 > 0.25 計 1 分

總分分級：≤1 低風險（綠）、2~3 中風險（橘）、≥4 高風險（紅）。

交通風險與辨識場景

風險類別 辨識場景 偵測方式與結果
標線磨損 斑馬線褪色、模糊 清晰度指標失分，給予重鋪建議
光線異常 強烈逆光或夜間過暗 能見度指標失分，建議調整拍攝時段
視線盲區 斑馬線過近車頭 駕駛視角底邊距過小，評估為盲區
空間壓迫 大型車輛或障礙物逼近 高度佔比過大，觸發空間壓迫指標

尚未支援說明

本系統目前尚未支援以下項目，需額外收集資料並重新訓練模型才能解鎖：

  • 紅綠燈號誌與燈號顏色辨識
  • 行人與車輛動態偵測
  • 未禮讓行人、違規停車等行為違規
  • 機車騎士未戴安全帽等取締項目

教學與架構

開發流水線：

  1. 使用 Roboflow 進行影像標註與資料集準備。
  2. 於 Google Colab 訓練 Ultralytics YOLO 模型。
  3. 將訓練好的模型權重匯出為 best.onnx 格式。
  4. 透過 ONNX Runtime Web 在瀏覽器純前端進行地端推論。

提示：開發者可直接修改程式碼上方的常數來調整評估門檻！

技術特色

  • 純地端推論：照片不上傳雲端，所有運算皆在使用者瀏覽器內完成，保護隱私。
  • YOLO 空間標定：精確抓取物件候選框並進行客戶端 NMS 過濾。
  • 像素分析引擎：利用 HTML5 Canvas 擷取原圖局部進行直方圖與灰階運算。
